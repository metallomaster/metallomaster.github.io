## 4. Проблемы

### SEO
- `H1` на каждой странице тупо дублирует `<title>` (включая хвост «- Производство изделий из металла»); `H2` нет вообще — семантической структуры текста нет.
- Нет `canonical`, нет JSON-LD / микроразметки (Organization, Product, BreadcrumbList — ничего).
- **HTTP не редиректит на HTTPS** — обе версии отдают 200 → дубли для поисковиков. Sitemap при этом ссылается на `http://`.
- Sitemap неполный: нет `ocinkovannie-vozduhovodi`, `vityazhnoj-zont`, `truba-ventilyacionnaya-kruglaya/pryamougoljnaya`, `zakazatj`.
- В meta description местами мусор (`<br />` внутри текста).
- До 45 картинок на страницу без `alt` (в основном галереи).
- Тексты — классический SEO-спам 2010-х («завидную репутацию у многочисленных потребителей»), вода, ключи натыканы в подряд идущие абзацы.
- Изображения: несжатые PNG, имена файлов местами кириллический мусор (`------_------_2024-03-01_210921-removebg-preview.png`).

### Адаптив
- `viewport width=1000` — мобильной версии нет. Google с 2019 индексирует mobile-first: это прямой удар по позициям.

### Техника
- Груда легаси-JS конструктора (7+ скриптов), jQuery ради ничего.
- `cache-control: max-age=5184000` (60 дней) на HTML — правки не доедут до посетителей.
- Внутренние абсолютные ссылки на `http://` (например, кнопка «Сделать заказ»).

### Юридическое
- **Нет политики обработки персональных данных и согласия на обработку** — форма заказа собирает контакты. По закону РБ «О защите персональных данных» № 99-З (07.05.2021) политика и согласие обязательны.
- Реквизиты продавца (ИП, УНП, адрес) в футере есть — это хорошо, сохранить.
- Нет режима работы, нет договора-оферты/условий заказа (для сайта-витрины без цен и корзины оферта не обязательна, но условия заказа желательны).
- Instagram ведёт на личный профиль — для доверия лучше брендовый.

## 5. Что обязательно сохранить при реворке

- **URL-структуру страниц** — сайт живёт в индексе с этими адресами; любые изменения URL только через 301-редиректы.
- Контентную структуру категорий и весь фотоархив работ (галерея — главный актив для доверия и для картинок в выдаче).
- Контакты, реквизиты, ID аналитики (GA/GTM).
- Ключевые запросы из title/description (дымоходы из нержавеющей стали Минск, колпаки на трубу, воздуховоды и т.д.) — они уже ранжируются.
