# План реворка metallomaster.by

> v2 (18.08.2026). Ключевые решения приняты — см. `03-decisions.md`: **Astro**, светлая индустриальная + тёмная тема (переключатель, дефолт по `prefers-color-scheme` через `color-scheme`/`light-dark()`), тексты переписываем, форма через сервис форм, без цен, деплой решаем в конце.

## Цели

1. Современный, быстрый, полностью адаптивный сайт (mobile-first).
2. SEO: сохранить текущие позиции (URL, ключи) и вырасти за счёт техники (Core Web Vitals, семантика, структурированные данные).
3. Богатая поисковая выдача: фото работ и данные компании прямо в сниппете/карточке.
4. Юридическая чистота: политика ПД, согласия, корректные реквизиты.

### Этап 1 — каркас проекта

- Git-репозиторий (первый коммит — документация), npm, Node LTS.
- Конфигуратор окружений: `.env.development` / `.env.production` (телефон, email, ключ Web3Forms, URL сайта) + типизированный конфиг-адаптер в `app/config`. В dev — тестовые контакты владельца для проверки писем и звонков.
- Логотип: перерисовка текущего «METALLOMASTER» в чистый SVG.
- Инициализация Astro-проекта; дизайн-система: токены (цвета, типографика, отступы) с двумя темами — светлая индустриальная (основная) и тёмная; переключатель темы, дефолт с устройства (`color-scheme`, `light-dark()`, `prefers-color-scheme`); сетка, компоненты (шапка, футер, карточка категории/товара, галерея с лайтбоксом, форма заказа, хлебные крошки).
- Обработка фотоархива: переименование файлов в осмысленные латинские слаги, конвертация в WebP/AVIF + fallback, генерация размеров (`srcset`).

### Этап 2 — страницы

Сохраняем текущие URL один-в-один (`*.html`). Состав:

- Главная: hero с УТП, категории, избранные работы, «как мы работаем», преимущества, контакты/CTA.
- Каталог, 5 категорий, ~20 страниц товаров (единый шаблон: описание, характеристики, галерея, CTA «Рассчитать/Заказать»).
- Контакты (карта, реквизиты, режим работы), Заказать (форма).
- Новые: политика обработки персональных данных; 404.

### Этап 3 — SEO-слой

- Уникальные `title`/`description` без хвостов-дублей; H1 ≠ title; иерархия H2/H3 в текстах.
- `canonical`, Open Graph + Twitter cards, `lang`, favicon-набор + webmanifest.
- JSON-LD: `Organization`/`LocalBusiness` (лого, адрес, телефон, geo, часы), `BreadcrumbList`, `Product`/`ItemList` на категориях/товарах, `ImageObject` для работ.
- Новый `sitemap.xml` (https, полный, с картинками — `image:image`), `robots.txt`.
- 301: http→https, www-склейка, все переименованные URL (если будут).
- Тексты: переписать полностью живым языком с сохранением ключевых запросов (решение принято).

### Этап 4 — адаптив и перфоманс

- Брейкпоинты 360 / 768 / 1024 / 1440; тач-таргеты ≥44px; меню-бургер.
- Бюджет: Lighthouse ≥ 90 по всем категориям на мобайле; LCP < 2.5s, CLS < 0.1.
- Ленивая загрузка галерей, `srcset`/`sizes`, критический CSS, без jQuery.
- Проверка в Playwright на реальных viewport'ах + скриншот-сравнение со старым сайтом.

### Этап 5 — юридическое

- Политика обработки персональных данных (закон РБ № 99-З), чекбокс согласия в форме заказа.
- Футер: полные реквизиты ИП, УНП, адрес, режим работы.
- Проверка прав на используемые изображения/шрифты (только собственные фото + шрифты с открытой лицензией).
- Cookie-уведомление (GA/GTM ставят куки).
