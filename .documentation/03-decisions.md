# Решения по проекту (зафиксированы 18.08.2026)

| Вопрос                 | Решение                                                                                                                                                                                                                                      |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Стек                   | **Astro** — статическая генерация, компоненты, встроенная оптимизация изображений                                                                                                                                                            |
| Архитектура            | **FSD (Feature-Sliced Design)** — слои `app / pages / widgets / features / entities / shared`, строгая декомпозиция сущностей, публичные API слайсов через `index.ts`, импорты только сверху вниз                                            |
| Переносимость          | Код должен переживать смену фреймворка (Astro → Next.js и т.п.): логика/стили/данные — фреймворк-агностичны, Astro-специфика только в `app/` и `pages/`. Детали — `04-architecture.md`                                                       |
| Деплой                 | **Пока локально**; хостинг/DNS решим в конце (этап 6 остаётся открытым)                                                                                                                                                                      |
| Дизайн                 | **Светлый индустриальный — основная тема**, плюс тёмная тема. Переключатель темы на сайте; по умолчанию тема подхватывается с устройства. Реализация через CSS `color-scheme` + `light-dark()` / токены                                      |
| Тексты                 | **Переписать полностью** живым языком, сохранив ключевые запросы                                                                                                                                                                             |
| Форма заказа           | **Web3Forms**: письма на email владельца, спам-защита, аккуратно оформленное письмо (структурированные поля, тема с названием изделия). Ключ владелец даст при подключении; до этого — dev-режим                                             |
| Конфигуратор окружений | Разные переменные для dev/prod: телефон, email, ключ Web3Forms, URL сайта. `.env.development` / `.env.production` + типизированный конфиг в `app/config` — чтобы владелец мог тестировать письма и звонки на своих контактах, не трогая прод |
| Пакетный менеджер      | **npm**, Node LTS                                                                                                                                                                                                                            |
| Логотип                | Перерисовать текущий «METALLOMASTER» в чистый SVG (узнаваемость сохраняем)                                                                                                                                                                   |
| Git                    | Репозиторий в корне проекта; первый коммит — вся документация; далее промежуточные коммиты после каждого этапа                                                                                                                               |
| Цены                   | **Без цен** — изделия индивидуальные, CTA «Рассчитать стоимость». JSON-LD Product без offer-цены                                                                                                                                             |
